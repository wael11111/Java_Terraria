# Jeu en 2D dans le style de Terraria
Ceci est un projet universitaire réalisé en 1ère année de BUT Informatique.  
Il s'agit d'un jeu vidéo reprenant les mécaniques emblématiques du célèbre jeu Terraria, développé en Java selon une architecture MVC.

## Contributeurs
- Djeneba DIALLO
- Adam ABERKANE
- Wael BEN MOUSSA

## Fonctionnalités
- Déplacement bidimensionnel du personnage et de sa caméra
- Gestion de l'inventaire
- Terraforming (modification de la composition du terrain)
- Interaction avec des personnages

## Technologies utilisées
- Java
- JavaFX (FXML)
- MVC (Modèle-Vue-Contrôleur)

## Installation et exécution

Le projet est une application Java développée avec JavaFX.

Pour des instructions détaillées concernant l’installation et le lancement du projet  
(depuis un IDE ou en ligne de commande avec Maven),  
[veuillez consulter le guide dédié](./HOWTO.md).

Des documents sont également disponibles dans le dossier `docs/`  
ainsi qu’un journal de bord illustrant l’évolution du projet.

## Direction artistique
L’univers du jeu s’inspire d’un style coloré et cartoon, rappelant notamment :
- l’esthétique "Sugar Rush" (Les Mondes de Ralph)
- l’esprit aventure et fantaisiste d’Adventure Time
- l’humour visuel du Monde de Gumball

Ces influences servent uniquement de référence artistique.
